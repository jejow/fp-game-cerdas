# Scene pengembangan

Sandbox, percobaan, dan scene integrasi asal dipisahkan di sini agar scene produk
mudah ditemukan. Folder ini tidak termasuk daftar scene build utama.

Konten tetap disimpan untuk referensi dan pemulihan. Kode sandbox yang masih ada
tetap dikompilasi Unity sesuai aturan folder/assembly-nya; pemindahan tidak
mengklaim bahwa semua konten folder ini dibuang dari kompilasi.

Scene game utama berada di `../Game/Scenes`.
