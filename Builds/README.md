# Build player

Builder proyek menghasilkan Windows 64-bit ke `Offline/Suna.exe`.
Jalankan executable bersama seluruh file pendamping di folder hasil build.

Build terbaru di folder Offline sudah tidak ada ketika penataan 15 Oktober 2026
dimulai. Cadangan lama disimpan terpisah sesuai catatan `Docs/MAINTENANCE.md`.
Tidak ada executable baru yang diklaim dari penataan folder ini.

Untuk membuat build dari kode sekarang, gunakan menu Unity
**Tools > Offline > Build Windows validation player** atau ikuti
[panduan build](../Docs/BUILD_AND_TEST.md).
