# Pemberitahuan pihak ketiga

Dokumen ini mencatat lokasi pustaka dan aset pihak ketiga. Lisensi, pemberitahuan hak cipta, dan atribusi yang disertakan vendor dipertahankan bersama sumber masing-masing; daftar profil kontributor dan halaman kredit personal tidak disertakan dalam game.

Dokumen ini tidak menetapkan lisensi baru atau mengubah kepemilikan sumber dan aset.

| Sumber | Lokasi |
| --- | --- |
| Wwise | `Assets/Wwise`, `Audio/WwiseProject` |
| Source SDK integrasi Wwise | `Tools/ThirdPartySources` |
| Volumetric clouds | `Assets/ThirdParty/VolumetricClouds` |
| Robot1F | `Assets/ThirdParty/Robot1F` |
| Placeholder karakter/senjata | `Assets/ThirdParty/PlaceholderAssets` |
| Travis Game Assets | `Assets/ThirdParty/TravisGameAssets` |
| Samples Unity | `Assets/Samples` |
| TextMesh Pro | `Assets/TextMesh Pro` |
| Font dan dokumen sumber | `Assets/Game/Art/HUD_General/nasalization_Police` |
| Package embedded | `Packages` |
