# Kredit dan sumber

Proyek berasal dari CSLike/SUNA, karya tim mahasiswa. Pengantar, gambar, dan daftar kontributor asal dipertahankan di [ORIGINAL_README.md](Credits/ORIGINAL_README.md). Instruksi multiplayer di dokumen tersebut bersifat historis; gunakan panduan offline saat ini untuk menjalankan game.
